# Dataset

The project uses a telecom customer churn dataset containing customer demographic, service, contract and billing information.

The dataset is used to demonstrate data preprocessing, feature selection and machine learning based churn prediction.

The target variable is `Churn`, where:
- `Yes` indicates that the customer churned.
- `No` indicates that the customer stayed.

The dataset file is intentionally kept separate from the source code so that the project structure remains organized.
